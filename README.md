# Поиск подстроки в строке

Командный проект. Каждый пишет
свой алгоритм в своём файле. Программа прогоняет все алгоритмы на всех
тестах, сверяет ответ с `std::string::find` и замеряет время.

## Контракт

Функция участника принимает структуру `DataSet` (поля `text` и `pattern`):

```cpp
int kmp_by_Starikov(const DataSet& dataset)
{
    // ищем dataset.pattern в dataset.text
}
```

- вернуть индекс первого вхождения `dataset.pattern` в `dataset.text` (счёт с 0);
- не нашлось — вернуть `-1`;
- пустой `pattern` — вернуть `0`;
- пример готового файла — `find_by_std.cpp`.

## Как участнику подключить свой алгоритм (3 шага)

1. Создать файл `<алгоритм>_by_<Фамилия>.cpp` и написать в нём свою функцию
   (смотри образец — `find_by_std.cpp`). Добавить файл в проект VS:
   правой кнопкой по проекту → Добавить → Существующий элемент.
2. Дописать объявление функции в `Participants.h` (одна строка, там есть пример).
3. Сказать капитану — он раскомментирует строку `//RUN(...)` в `main.cpp`.

Тесты: дописываем одной строкой **в конец** списка в `dataset.cpp`.
Твой алгоритм должен работать на всех тестах, не только на твоих.

**Ошибка** = ответ не совпал с `string::find` (в таблице время станет `-1`),
программа упала или не собирается. Ошибки не коммитим.

## Как запустить

1. Открыть `substring_search\substring_search.slnx` в Visual Studio.
2. Сверху выбрать **Release** и **x64**.
3. **Ctrl+F5**.

Итог — таблица с колонками через табуляцию: `dataset  n  m  method  author
answer  time_us`. Та же таблица лежит в файле **`result.txt`** (рядом с
`.slnx`) — оттуда капитан строит график в Excel.

## Git (кнопки в Visual Studio)

**Участник один раз:**
1. Принять приглашение на GitHub.
2. **Git → Клонировать репозиторий** → вставить ссылку.
3. Переключиться на ветку `develop` (окно «Репозиторий Git» → правой кнопкой
   по ветке → Извлечь).

**Рабочий цикл (окно «Изменения Git»):**
1. **Вытягивание** (стрелка вниз) — забрать чужие изменения. Всегда первым делом.
2. Пишешь код → Release → Ctrl+F5 → твои строки в таблице без `-1`.
3. Сообщение коммита → **Зафиксировать все**.
4. **Push** (стрелка вверх).

В `main` ничего не пушим — туда капитан перенесёт всё одним PR в конце.
Ошибку нашёл — пишем в **Issues** на GitHub.
