## Правила

Каждый пишет в своём файле функцию:

```cpp
int xxx_search_Фамилия(const std::string& text, const std::string& pattern);
```

- вернуть индекс первого вхождения `pattern` в `text` (счёт с 0);
- не нашлось — вернуть `-1`;
- пустой `pattern` — вернуть `0`;
- пример готового файла — `std_find.cpp`;
- правим только свой `.cpp`; тесты дописываем одной строкой **в конец**
  списка в `dataset.cpp`;
- твой алгоритм должен работать на всех тестах, не только на твоих.

**Ошибка** = ответ не совпал с `string::find`, программа упала или не
собирается. Ошибки не коммитим: исправил → прогнал → всё OK → коммит.

## Как запустить

1. Открыть `substring_search\substring_search.slnx` в Visual Studio.
2. Сверху выбрать **Release** и **x64**.
3. **Ctrl+F5**.

Программа печатает таблицу в консоль и одновременно пишет её в **`result.txt`**
(рядом с `.slnx`, в папке `substring_search`): тест, алгоритм, `n`, `m`,
найденный индекс, время в микросекундах, статус OK/FAIL. Для графика капитан
переносит данные из `result.txt` в Excel.

## Git (кнопки в Visual Studio)

**Участник один раз:**
1. Принять приглашение на GitHub.
2. **Git → Клонировать репозиторий** → вставить ссылку.
3. Переключиться на ветку `develop` (окно «Репозиторий Git»).
4. Открыть `.slnx` — проект готов, ничего создавать не надо.

**Рабочий цикл (окно «Изменения Git»):**
1. **Вытягивание** (стрелка вниз) — забрать чужие изменения. Всегда первым делом.
2. Пишешь код → Release → Ctrl+F5 → все тесты OK.
3. Сообщение коммита → **Зафиксировать все**.
4. **Push** (стрелка вверх).

Ошибку нашёл — пишем в **Issues** на GitHub, чиним, закрываем.
